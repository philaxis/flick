**桌面变成网格。** 一个架子（行）放同一项工作的桌面，上下切换其他架子。只有架子可以命名。

**按住再推。** 按住触发键,把鼠标往一个方向推,就往那边移动一格。指针留在原地。

**轻点看全部。** 轻点触发键,会显示当前桌面的窗口和一张小地图。把窗口拖到地图的格子上就能移过去。

**按键随你定。** 默认是鼠标的“前进”侧键。右键点击托盘图标 → *设置…* → *更改*,按下你想用的按键即可,也可以同时按几个键。

**小巧免费。** 一个不到 1 MB 的 exe。不用注册,没有安装向导。开源,MIT 许可。

**三指触摸板。** 将 Windows 三指滑动和点击设为“无”后，在 Flick 设置中启用；轻点打开面板，按住并移动约 1 厘米切换一个桌面。默认像触摸滚动一样推动屏幕，与手指方向相反；鼠标则跟随手的方向。

**鼠标和触摸板各自设置。** 设置里有 *鼠标* 和 *触摸板* 两个标签页。每页分别设置左右(同一架子内)和上下(切换架子):切换一个桌面要移动的距离(鼠标用原始计数而非像素，实际移动距离取决于鼠标 DPI,触摸板用毫米),以及每个桌面停住的力度(*卡点*,关闭 表示均匀跟随手)。*反向* 让该设备反向。config.toml 中对应 `[mouse]` 和 `[touchpad]` 下的同名设置;旧版本的 config.toml 会被当作鼠标设置读取。

**画面跟随手。** 打开 *跟随手*(默认开启,每个方向分别设置)后,桌面会像 Mac 一样随鼠标或手指滑动,下一个桌面随之进入视野,松手时只切换一次:切到最近的桌面,快速甩动则按惯性切得更远。固定到所有架子的窗口保持不动,固定到本架子的窗口在左右移动时保持不动。关闭后,手每到一个桌面就立即切换。鼠标标签页的跟随手开关也控制键盘快捷键切换动画。

**屏幕就是地图。** 移动时屏幕会向后退，上下左右和斜对角相邻的桌面各露出一格；中间的桌面稍大、更亮，像浮在前面，屏幕顶部显示当前架子的名字。在同一架子内左右移动时只有这个架子滑动，上下的架子保持不动。移动时出现的小地图默认关闭，可在设置中打开 *移动时显示小地图*（或在 config.toml 中设置 `minimap = true`）。

**固定与置顶分开。** 面板按钮依次切换 *关闭 → 本架子 → 所有架子 → 关闭*。固定菜单（`Ctrl+Alt+Win+P`）使用相同状态，再选已勾选项即关闭。*置顶*是独立按钮。*应用:* 表示继承自整个应用的固定，只能通过菜单中的应用选项更改；单个窗口的按钮不会解除同一应用其他窗口的固定。

**用键盘设置。** Tab / Shift+Tab 移动可见焦点，方向键调整滑块，Space / Enter 激活按钮或开关。Ctrl+Tab 切换设备标签页，1 / 2 仍可使用。窗口限制在显示器工作区内，需要时可用滚轮、滚动条或 Page Up / Page Down 纵向滚动，键盘焦点会自动滚入视野。设置与指南遵循 Windows 显示语言（韩语、中文，其他为英语），指南显示当前触发键名称。

**安静启动。** 在设置中主动开启 *以管理员身份运行* 才请求提升权限；拒绝或推迟后，下次启动不会再次请求 UAC。关闭后从下次运行起生效，当前进程在重启前保留权限。托盘位置气泡仅在首次完成指南时显示。悬停预览仍立即出现；已停用的 `dwell_ms` 被忽略，可从旧 config.toml 中移除。

## 开始使用

1. 用上面的按钮下载并运行。它会自行安装,并随 Windows 启动。
2. 按住触发键,把鼠标往旁边推。
3. 轻点触发键,在地图上按 **+** 添加桌面或新架子。

## 须知

- 支持 Windows 11 23H2(内部版本 22631.3085 及以上)、24H2(内部版本 26100.2605 及以上)和 25H2。在其他版本上只会提示,不会启动。
- 卸载:设置 → 应用 → 已安装的应用 → Flick。

## 构建

在 Windows 上运行 `cargo build --release`,在 WSL 中运行 `scripts/build-wsl.sh build --release`。
