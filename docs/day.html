앞선 맥 러너에서 안전한 연결·소스 전송·도구 설치·빌드·회수·정리를 확인했습니다. 이번 추가 명령의 러너 결과는 아래에 갱신합니다.
Flick 앱은 아직 맥판 구현이 없습니다. 현재 build-flick는 실제 Swift 시험 도구를 빌드하고 회수합니다. 입력 훅·창 이동·화면 밖 창 캡처를 친구 맥에서 시험합니다.
macOS 통합 로그는 표준 계정에서 권한 부족으로 거부됩니다. 앱 로그·크래시 회수는 됩니다. 관리자 권한을 올리지 않았습니다.
