가상 데스크톱을 2D 격자로Virtual desktops, as a 2D grid

버튼을 누른 채 마우스를 툭 밀면 그 방향의 데스크톱으로 넘어갑니다. 행은 워크스페이스, 그 안의 칸은 그 작업의 화면입니다.

Hold a button, flick the mouse, and you are on the desktop in that direction. Rows are workspaces; the cells in a row are that workspace’s desktops.

One file, about 0.7 MB. Runs on Windows 11 23H2 (build 22631.3085 or later). 24H2 is not supported yet.

설치와 요구 사항Install and requirements

동작은 세 가지입니다Three gestures

기본 트리거는 마우스 옆면의 “앞으로” 버튼입니다.

The default trigger is the “forward” button on the side of the mouse.

  1. 01

    누른 채 밀기 — 한 칸 이동Hold and flick — move one cell

    트리거를 누른 채 마우스를 밀면 그 방향으로 한 칸 넘어갑니다. 누르고 있는 동안 커서는 제자리에 멈춰 있고, 작은 미니맵이 지금 위치를 보여 줍니다.

    Hold the trigger and flick the mouse: you move one cell in that direction. The cursor stays frozen while you hold, and a small minimap shows where you are.

  2. 02

    위아래 — 워크스페이스 전환Up and down — switch workspace

    위아래로 밀면 다른 행으로 가고, 그 행에서 마지막에 있던 칸에 도착합니다. 처음 가는 행은 첫 칸입니다. 지도는 각 행을 좌우로 밀어서, 도착할 칸들이 지금 칸의 바로 위아래 한 열에 오도록 보여 줍니다.

    Flick up or down to change rows. You land on the cell that row was last left on, or its first cell if you have not been there. The map slides each row sideways so the landing cells line up in one column, directly above and below where you are.

  3. 03

    딸깍 — 전체 뷰 열기Click — open the board

    밀지 않고 트리거를 딸깍 누르면 화면 전체에 뷰가 열립니다. 선택한 칸의 창들이 크게 보이고 아래에 작은 지도가 있습니다. 다시 딸깍하거나 Enter를 누르면 그 칸으로 가고, Esc는 취소입니다.

    Click the trigger without moving and a full-screen board opens: the selected cell’s windows at large size, with a small map below. Click again or press Enter to go to that cell; Esc cancels.

  • 트리거는 다른 마우스 버튼이나 키로 바꿀 수 있고, W+E+R처럼 여러 키를 함께 누르는 방식도 됩니다.
  • The trigger can be another mouse button or a key, or a chord such as W+E+R.
  • Shift를 함께 누른 채 밀면 지금 쓰는 창을 들고 이동합니다.
  • Hold Shift as well and the active window comes with you.
  • 키보드로는 Ctrl+Alt+Win+방향키로 이동합니다.
  • On the keyboard, Ctrl+Alt+Win+arrow keys does the same.
  • 모니터가 여러 대면 모든 모니터가 함께 전환됩니다. 윈도우 가상 데스크톱이 원래 그렇게 동작합니다.
  • With several monitors, all of them switch together. That is how Windows virtual desktops work.

전체 뷰: 창은 크게, 지도는 작게The board: large windows, small map

윈도우의 작업 보기와 비슷한 화면입니다. 선택한 칸의 창이 실시간 미리보기로 크게 보이고, 격자 전체는 아래에 작은 지도로 들어갑니다.

It works like Task View. The selected cell’s windows appear as large live previews, and the whole grid sits below as a small map.

  1. 1

    선택한 칸의 창The selected cell’s windows

    창마다 앱 이름과 제목, 닫기 버튼이 붙습니다. 뷰가 열린 채 밀거나 방향키를 누르면 선택한 칸만 바뀌어서, 가지 않고도 다른 칸을 들여다볼 수 있습니다.

    Each window shows its app name, title and a close button. Flick or press the arrow keys while the board is open and only the selection moves, so you can look into other cells without going there.

  2. 2

    고정 버튼 하나One pin button

    창마다 있는 버튼을 누를 때마다 다음 상태로 넘어갑니다.

    Each window has one button that steps through three states.

    꺼짐Off→워크스페이스 안에서 따라옴Follows you in its workspace→모든 데스크톱에 표시Shown on every desktop
  3. 3

    창을 끌어 옮기기Drag a window to move it

    미리보기를 지도의 칸 위로 끌어다 놓으면 그 창이 그 칸으로 옮겨집니다. 지도의 칸에는 그 안에 있는 앱 아이콘과 창 개수가 보입니다.

    Drop a preview onto a map cell and the window moves to that cell. Each map cell shows the icons of the apps in it and how many windows it holds.

  4. 4

    격자 고치기Edit the grid

    칸을 끌어 순서를 바꾸거나 다른 행으로 옮기고, 칸과 행을 더하거나 지웁니다. 행의 길이는 서로 달라도 됩니다.

    Drag cells to reorder them or move them to another row, and add or remove cells and rows. Rows do not have to be the same length.

설치와 요구 사항Install and requirements

  1. Flick.exe를 받아 한 번 실행합니다.Download Flick.exe and run it once. 스스로 %LOCALAPPDATA%\Flick에 설치하고, 시작 메뉴와 윈도우 시작 시 자동 실행에 등록한 뒤 바로 실행됩니다. 따로 깔아야 하는 런타임은 없습니다. It installs itself to %LOCALAPPDATA%\Flick, adds a Start menu shortcut, registers to start with Windows, and starts running. There is no runtime to install.
  2. 마우스의 “앞으로” 버튼을 누른 채 밀어 봅니다.Hold the mouse “forward” button and flick. 트리거 같은 설정은 트레이 아이콘을 우클릭해 여는 설정 파일에서 바꿉니다. Settings such as the trigger live in a config file you open from the tray icon’s right-click menu.
  3. 지울 때는 설정 → 앱 → 설치된 앱 → Flick → 제거.To remove it: Settings → Apps → Installed apps → Flick → Uninstall. 설치하지 않고 그 자리에서만 실행하려면 Flick.exe --portable. To run it in place without installing: Flick.exe --portable.

윈도우 11 24H2 — 아직 지원하지 않음Windows 11 24H2 — not supported yet
Flick은 문서화되지 않은 윈도우 인터페이스로 가상 데스크톱을 전환하는데, 이 인터페이스가 윈도우 빌드마다 다릅니다. 24H2용은 아직 맞추지 못했습니다.
Flick switches desktops through an undocumented Windows interface that differs from build to build. It has not been adapted to 24H2 yet.

내 버전 확인: Win+R을 누르고 winver를 입력합니다.

To check your version: press Win+R and type winver.
